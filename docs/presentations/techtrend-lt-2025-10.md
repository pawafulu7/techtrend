# TechTrend LT資料（2025年10月版）

## 1. このLTで共有したいこと
- 個人開発で進化させている技術記事アグリゲーター「TechTrend」の現状と裏側
- ここ半年で取り組んだ品質・セキュリティ改善のハイライト
- 次フェーズで試したいアイデア（vibes検索や海外速報翻訳）へのフィードバック募集

## 2. プロダクトのスナップショット
- 収集ソース41件（AI/LLM 6、企業ブログ13、技術メディアその他22）
- ストック記事数: 開発環境 10,013件 / 本番環境 3,897件
- タグ総数 8,611件、人気タグはAI/AWS/JavaScriptなど技術系に最適化済み
- 1時間ごとのRSS収集 + 12時間ごとのスクレイピング + 日次品質バッチ
- 要約・翻訳はGemini 2.5 Flash、全テスト1,812件パス（ESLint/TSエラー0）

## 3. ユーザー向け価値
- 記事一覧要約・詳細要約・タグ・品質スコアを自動生成し、短時間でトレンド把握
- /popular, /trends, /digest, /dashboard/performance で多角的に記事を発見
- お気に入り・未読管理・ダークモード・メール送信（nodemailer v7対応済み）
- 国内外のソースを統一UIで横断検索できるニュースレター的ハブとして活用中

## 4. データパイプラインとアーキテクチャ
```
情報源 (RSS / API / スクレイピング)
  → Fetchers (41種の専用/汎用フェッチャー)
    → Enrichers (全文取得・サムネ・論文メタデータ)
      → AI Summary Service
        [Transport → Adapter → Service + QualityChecker → PostProcessor]
          → PostgreSQL (Prisma) / ProcessingLog
            → Redis + DataLoader (L1/L2キャッシュ)
              → Next.js 15 App Router UI & API Routes
```
- 依存性注入（lib/di）でテスト容易性を確保、Gemini呼び出しは指数バックオフ付き
- OpenTelemetry + Grafana/Tempo/Loki + New Relicでトレースとメトリクスを監視

## 5. AI要約と品質管理の工夫
- INSTRUCTION_PATTERNSを22種類に統一し、プロンプト漏れを完全ブロック
- フォールバック要約でも指示文を除去しつつ有用情報を残すサニタイズを追加
- Quality Checkerで言語・文字数・禁止フレーズを判定、再生成フローを自動化
- Google/AWS専用エンリッチメントで短文RSS問題に対応、最低500文字を保証

## 6. 2025年10月の主な改善ハイライト
- ユーザー削除API（ソフトデリート + 監査ログ + JWT即時無効化）をリリース
- Strict CSP / Permissions-Policy / HSTS を middleware.ts へ集約、XSS耐性を向上
- GitHub Actions の Prisma migrate タイムアウトと YAML 構文エラーを解消し安定稼働
- 企業ブログのデータ欠落と短文化を修正、再エンリッチで17記事を再生成
- タグ品質を保つ自動チェックワークフローと監視スクリプトを追加

## 7. 運用・信頼性の状況
- GitHub Actions スケジューラ（RSS毎時/スクレイピング12時間/品質日次）が復旧済み
- Dockerベースのテストランナーでビルド・Lint・ユニット・E2Eを完全自動化
- セキュリティアラート（Dependabot/CodeQL）はゼロ、ヘッダ強化もフェーズ完了
- ProcessingLogと差分タイムスタンプで事故時に原因を追跡しやすい構成

## 8. これから挑戦したいこと
- Mastra を使った「vibes検索」エージェント：要約・タグをベクトル化し感覚的検索を実現
- 海外記事速報翻訳フローの整備（要約 + 出典リンク中心、許諾プロセスの検討）
- プロンプトA/Bや難易度推定の可視化、ダッシュボードでの品質メトリクス強化
- マネタイズ実験：プレミアム要約、データ/API提供、コミュニティ運営などの検証

## 9. フィードバック募集中

- こんな指標が欲しい・ここがわかりづらい等、日常利用での気付き
- コラボしたい企業ブログ/AIソース、監視や自動化の改善案
