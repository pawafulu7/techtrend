## 📝 更新ガイドライン

### ドキュメント更新のタイミング

1. **タスク完了時**: チェックリストのチェックボックスを更新
2. **週次レビュー時**: 進捗管理サマリーを更新
3. **月次レビュー時**: KPIと優先度を更新
4. **四半期レビュー時**: 分析レポートを再作成

### 更新手順

```bash
# 1. ファイルを編集
vim docs/analysis/action-items-checklist.md

# 2. 進捗率を計算して更新
# 完了タスク数 / 総タスク数 × 100

# 3. コミット
git add docs/analysis/
git commit -m "docs: update project analysis progress"
git push
```
